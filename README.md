# Lighthouse Luxury — Private Client Decision Room

Responsive product prototype for a luxury property advisory hiring assignment. It uses a company-level brand and a generic private-client workspace rather than the fictional family's name.

## Run locally
Open `index.html` directly, or use any static web server.

## Deploy to Vercel
1. Upload this folder to a GitHub repository.
2. Import it at https://vercel.com/new.
3. For a static site, use the default static deployment settings. No build command or environment variables are required.
4. Deploy and test on desktop and mobile.

## Notes
The family case figures are fictional assignment inputs. Rent and transaction-cost figures are illustrative assumptions. Market links are included for further checking. This prototype is not investment, tax, or legal advice.
